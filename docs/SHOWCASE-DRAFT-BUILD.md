## Repeating the build

Use [the builder skill](../skills/indy-picker-site-builder/SKILL.md) with a fresh per-site journal and the actual authorized target. The retained local execution folder is `planning/website-templates/showcase-draft-build/` in the INDY workspace; its README, process checklist, build journal and evidence retain the detailed source/destination mappings and exceptions. That folder is not bundled into this repository.

The main verified authoring lessons are:

1. Create the final-named Page, close it, then reopen through inventory Edit before adding Sections. Wait for the saved Title, slug and editable child list.
2. Set Section Type before its final Name. Record the generated destination scope and verify it after saving.
3. For Custom Sections, verify visible HTML before saving code, iframe content before saving the Section, and body content after reopening the Page. Keep clipboard ownership serialized.
4. Use parser-safe, fully scoped CSS in Custom Sections; inspect its native round trip. Preserve native widget owners and their separate settings.
5. Check native inventory after errors before retrying. Code 903 sometimes accompanied persisted fields or records, while these Library imports created no destination records.
6. Check actual browser width for phone breakpoints, reset temporary overrides, and keep Admin evidence distinct from consumer evidence. Do not publish to obtain draft QA.

Future reference sites use the approved `template-<name>-indy-consumer` address namespace at provisioning. Showcase retains its accepted working address.
