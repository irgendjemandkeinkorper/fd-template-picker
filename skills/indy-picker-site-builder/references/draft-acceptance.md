# Draft acceptance and handoff

## Journal the distinctions

Create a local per-site build journal containing the export SHA/catalog/module index digests, user-authorized target/actions, proposed and actual IDs, every created Page/Section, field owner and readback hash, current Library state, final ordered Section IDs, native saved/unpublished states, immediate-effect Theme/navigation settings, dependency mappings, evidence times and unresolved issues. Keep source identities in a separate source mapping. Record requested paths versus actual generated routes.

No successful click proves completion. Read the native saved values after reopen. An enabled Save button can mean unsaved changes; a disabled Save button plus matching readback provides stronger saved-state evidence. Explicit Page-row published/unpublished state is still separate. Existing Page rows can show the older published title/count; inspect the draft editor.

## Check the intended draft

- Confirm one chosen style per required component, actual navigation labels, complete composite hero children and selected order. The purpose of the Private Parties component is private hire; a generic film-programme Events block is not equivalent.
- Check desktop and phone text containment, images, overlay backing/shadows, controls, prices, category labels and no horizontal scrolling. Wait for async widgets/media before sampling; a skeleton/loading caption is not complete evidence.
- Verify native compiled CSS scope matches each final-named Section and typography comes from the package rather than accidental source Theme inheritance.
- Check Primary/Secondary and Dark/Background, derived CTA/tint pairs, protected caption foreground/backing, hover/focus, native errors/status and any configured seat states. The picker's two base-pair checks cannot certify arbitrary rendered pairs or photo overlays. Preserve recorded Header/Accent alias limitations.
- Verify expected approved destination sample items/media and catalog filters; empty settings can intentionally bind local categories. Dynamic source IDs are not configuration defaults. A populated movie list is not proof of bookable sessions or checkout.
- For forms, inspect destination configuration and validation without sending real enquiries unless explicitly authorized. Check intended links without submitting purchases, memberships or real ticket transactions.
- Reopen Library imports to confirm Not Linked; check native history/record states and source independence as needed. Never Force Update to resolve a local draft style issue.

Admin's simulated phone can use the outer browser viewport for `vw` sizing; Admin previews also use the framework palette. They establish draft structure/layout under that preview, not real consumer phone behavior or customer Theme output. If an unpublished page redirects to the homepage, record public draft QA as unavailable. Do not publish merely to complete a QA checklist. A later release can authorize a staging/publication path and real desktop/phone checks.

## Stop for review

Report the exact Region / Circuit / Site, final site name, selected mix and export SHA. Give a short table of created objects, state and review evidence, clearly separating saved Page drafts from immediate-effect site settings and any authorized hosted shell. Include pending content/media/portability/consumer checks and narrow rollback through the created objects/history. Removing a Site/Circuit, unpublishing or deleting seeded data requires its own authorization; do not perform cleanup by assumption.

When all work that can be done in draft is complete, stop. No Page/Global Widget publish, register push, custom domain, real transaction or deploy follows automatically. If module readiness blocked assembly, deliver the concrete packaging plan instead of “site complete.” If a provision operation had an unknown outcome, record it and resolve the scoped inventory before any retry.
